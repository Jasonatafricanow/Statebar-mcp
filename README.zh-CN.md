# Statebar MCP

[English](README.md) | [简体中文](README.zh-CN.md)

把用户观察转为当前状态快照的小型 MCP / REST 服务：刚睡醒、计划变更、症状和正在进行的活动。

**语言支持：**内置中文规则，并增加小范围英文整句规则，覆盖醒来、准备睡觉、头痛及缓解、已服药。不代表任意英文对话的同等覆盖。可选模型抽取是需要单独配置的另一条路径。

## 为什么需要对账

聊到睡眠不等于用户正在睡觉。助手发言不能确立用户状态，旧观察不能覆盖新状态，新的用户互动可以推翻“正在睡觉”。例如 `我刚睡醒` 与 `I just woke up.` 均可触发醒来观察；英文规则要求完整的第一人称陈述，不接纳引用、否定、条件、历史或第三人称示例。

## 运行与验证

```bash
python -m pip install -e ".[dev,mcp]"
statebar-mcp mcp
# 另一种传输方式：
statebar-mcp serve --host 127.0.0.1 --port 8765
# 测试：
python -m pytest -q
```

目前文档使用源码安装。客户端配置、状态语义和隐私设置见[实现说明](docs/IMPLEMENTATION.md)。

## 接口与边界

五个 MCP 工具提供观察、快照、上下文候选、状态和健康检查。SQLite 在本地存储状态。启用可选 LLM 抽取后，用户文本会发送到配置的端点。MCP 初始化声明实现支持的 `2024-11-05` 协议，不再原样回显任意客户端版本。更广泛的英文覆盖和包发布仍属后续工作。
